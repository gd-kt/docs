# Getting Started

[![Jitpack Badge](https://jitpack.io/v/gd-kt/trigg.svg)](https://jitpack.io/#gd-kt/trigg)

To download trigg, you can use `jitpack`:

```gradle
repositories {
    maven { url = uri("https://jitpack.io") }
}

dependencies {
    implementation("com.github.gd-kt:trigg:<version tag>")
}
```

You can check for the latest version on the [github](https://github.com/gd-kt/trigg/releases/latest)
or on the Jitpack badge above.
